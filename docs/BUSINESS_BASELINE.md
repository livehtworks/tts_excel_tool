# 旧版业务功能冻结基线

来源：`tts_excel_tool_code_20260818_141950.zip` 中最新 `app.py` / README。本文只冻结**业务行为**，不冻结 FastAPI/Python/PowerShell/Piper 子进程等实现。

## A. Excel / 语料播放业务（重写必须保留）

1. 打开 `.xlsx` 文件并读取 Sheet 列表。
2. 选择单个 Sheet。
3. 可指定表头行，不假设固定为第 1 行。
4. 分析有效列：
   - Excel 列号；
   - 表头；
   - 非空数量；
   - 最多 5 个样本；
   - 建议类型：meta / utterance / result / unknown；
   - 语言猜测。
5. 列映射：
   - 启用 / 禁用；
   - 用途：忽略 / 参考列 / 播放列；
   - 语言；
   - TTS engine/voice；
   - 全选 / 全不选；
   - 批量设置用途。
6. 参考列当前最多 1 列；播放列至少 1 列。
7. 映射配置按 Excel + Sheet + 表头行持久化；再次打开自动回填。
8. 运行视图：
   - 参考列排在播放列前；
   - 每个播放列后插入结果列；
   - 第一列为序号；
   - 播放列单元格存在多行文本时按换行展开成多条；
   - 同一原始行的参考值重复到展开行；
   - 某播放列不足最大行数时该展开行留空；
   - 全空展开行过滤；
   - 保留 raw row / expanded index / segment index 元数据，后续编辑必须能回写到正确源位置。
9. 单元格播放：点击某个播放单元格即可播放该句。
10. 顺序播放：
    - 指定播放列；
    - 起始行 / 结束行；
    - 句间隔；
    - 语速 0.5~2.0；
    - 暂停 / 继续 / 停止；
    - 当前播放位置高亮。
11. 人工结果：播放列对应结果列循环 `空白 -> OK -> NG -> 空白`（旧版符号为 `✔/×`）。
12. 运行视图中的参考/播放文本允许编辑；结果列不作为普通文本编辑。
13. 导出“当前运行视图”为 XLSX。
14. 日志必须保留，但日志系统不应成为业务状态容器。

## B. 旧版语言识别行为（需要迁移，允许修正明确 bug）

旧版已有 37 个 locale 选项，包含：

`zh-CN, zh-TW, en-US, en-GB, ja-JP, ko-KR, de-DE, fr-FR, it-IT, es-ES, pt-PT, pt-BR, ru-RU, ar-SA, th-TH, vi-VN, id-ID, ms-MY, tr-TR, nl-NL, pl-PL, cs-CZ, hu-HU, ro-RO, sv-SE, da-DK, fi-FI, no-NO, el-GR, he-IL, hi-IN, bn-BD, ur-PK, fa-IR, uk-UA, km-KH`。

必须保留的识别意图：

- 中文业务表头前缀优先，如“英语… / 阿语… / 西语…”。
- ENG/ENU/FRF/DEU/SPM/ARG 等地区或项目缩写可映射。
- “说法举例”本身不得宽泛默认成中文。
- 当前规则优先级高于旧错误持久化配置；旧错误配置不得永久覆盖新识别结果。

## C. 新增文本自动对比业务（新架构必须加入）

### 输入

- 正式文本序列；
- 机器文本序列；
- 文本至少具有“一条一条”边界，或可由固定分隔符切开；
- 后续 UI 可从 TXT/CSV/XLSX 导入，但核心层只接受 `vector<string>`，不与文件格式绑定。

### 对齐

1. 原始文本 `raw_text` 永远保留，不能为了匹配修改输出内容。
2. 使用 `normalized_text` 做匹配。
3. 对齐阈值和 OK/NG 阈值必须是两个独立参数：
   - 对齐阈值：判断两句能否成为候选对应项；默认 80；
   - 合格阈值：对应成功后是否 OK；默认 100，可配置。
4. 不能“每条正式文本独立找全库最相似文本”然后允许同一机器句被重复占用。
5. 第一版固定使用：高置信度唯一锚点 + 顺序约束全局对齐；支持 MATCH / MISSING / EXTRA。
6. 当低于对齐阈值时不得强行匹配，必须显式留下 MISSING/EXTRA。
7. 字符差异按 Unicode code point 计算，禁止 UTF-8 byte 级 Diff。

### 输出

对每组语言至少导出：

- 正式文本；
- 机器文本；
- 相似度；
- 结果（OK / NG / MISSING / EXTRA）。

正式文本与机器文本两个单元格都要支持富文本差异：

- 删除/替换的正式字符标红；
- 插入/替换的机器字符标红；
- 无差异片段保持默认文字颜色。

## D. 明确不迁移的旧实现

以下属于旧技术债，不是业务功能：

- FastAPI；
- 浏览器自动打开；
- HTML/JS 巨型内嵌页面；
- 全局 `runtime_state` 字典；
- PowerShell + System.Speech；
- pyttsx3；
- MMS/XTTS/Kokoro 的“失败自动回退到占位 TTS”；
- 每句调用 `piper.exe`；
- temp WAV + winsound 作为主播放链；
- PyTorch/Transformers 作为桌面工具运行时；
- HTTP API 作为本地 GUI 内部通信层。
